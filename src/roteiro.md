# Roteiro React

Esta é uma lista de tarefas a serem realizada para concluir a atividade.

## Repositório

## Projeto

- Criar o projeto React com Vite 
- Criar um input na tela
- Criar o primeiro código na tela com texto
- Relacionar o input com o texto mostrado através de um State
- Criar um componente que encapsula o input e o texto mostrado
- Realizar em componentes controlados
- Duplicar input
- Trocar para Usuário e Senha
- Checkbox para termo de uso não controlado
- Armazenar valor de credencial em LocalStorage
- Validar formulário
- UseEffect pra ler dinâmicamente
- Testar estilo de página
